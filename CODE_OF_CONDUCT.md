# Code of conduct

We want contributors of every background and experience level to feel welcome.
Be respectful, assume good intent, give constructive feedback, and focus
disagreement on ideas and code.

Harassment, discriminatory language, threats, sexualized attention, doxxing, and
repeated personal attacks are not acceptable. Respect people's privacy and
requests to stop unwanted contact. These expectations apply to project issues,
pull requests, discussions, and other spaces where you represent the project.

Report misconduct privately through the contact options on a maintainer's GitHub
profile: [David](https://github.com/david-cyman-argyle) or
[Ted](https://github.com/ted-cyman-argyle). If a report concerns one maintainer,
contact the other. Do not post sensitive details in public issues.

Maintainers will review reports, protect reporter privacy as far as practical,
and respond according to severity and patterns of behavior. Responses may include
a request to change behavior, removal of content, a warning, temporary
restrictions, or removal from project spaces. Maintainers are accountable to
these expectations too.
